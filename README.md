
# TravelBharat – Explore India State by State

## Overview

TravelBharat is a modern and responsive tourism information website designed to help users explore India state by state. The platform provides structured information about Indian states, cities, tourist destinations, culture, heritage, nature, adventure, and religious places.

The main goal of TravelBharat is to provide tourism information in a simple, attractive, and user-friendly way so that travelers, students, and researchers can easily discover destinations across India.

---

## Features

- Explore India state by state.
- State-wise tourist destination information.
- City-wise tourism details.
- Explore popular tourist places.
- Category-based destination exploration.
- Attractive destination cards with images.
- Individual state detail pages.
- Individual city detail pages.
- Responsive design for desktop, tablet, and mobile.
- Modern navigation bar.
- Hero section with tourism-focused design.
- Search functionality for destinations.
- Dark mode support.
- Interactive UI elements.
- Hover effects and smooth animations.
- Back-to-top button.
- Clean and user-friendly interface.
- Mobile-friendly navigation menu.

---

## Main Sections

### Home

The Home page introduces TravelBharat and provides users with quick access to different tourism sections.

### Explore

The Explore section allows users to discover popular tourist destinations and cities across India.

### States

The States section displays Indian states in attractive cards. Users can select a state to view detailed information about that state.

### Categories

Tourist destinations are organized into different categories such as:

- Heritage
- Nature
- Adventure
- Religious

### About

The About section explains the purpose of TravelBharat and its objective of making Indian tourism information easier to explore.

### Contact

The Contact section provides a simple way for users to connect with the platform.
